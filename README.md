# Warehouse Safety Simulator V18

Synthetic 92×58 warehouse demo with six selectable safety-rule proxies.

Changes: synthetic SR-009 external route bypasses, rack width fixtures for SR-016 and SR-018, SR-012* forklift/robot bay reservation proxy, frame-dependent agent tags.

**Not a certified safety model.** SR-012 in the thesis refers to the electric-jack handover; here SR-012* illustrates a forklift/robot occupancy proxy instead. Uses hypothetical grid dimensions, routes and thresholds. All routes, completion, and tag durations are scenario-dependent and should be browser-tested.

Deploy: upload `index.html` at repository root; Settings > Pages > Deploy from branch > main > /(root).
