SR-009 / SR-016 / SR-018 / SR-024 / SR-042 / SR-012 behavior

SR-009: Robot limited to Robot Operation Area / Bay; forklift footprint excluded from Handover Bay and Waiting Zone; human worker footprint excluded from Robot Operation Area (handover/wait exceptions only). SR-016+018: coordinated static hazard clearance and narrow-corridor restrictions, including entire 2×3 forklift footprint. SR-024: all agent types avoid 1×1 moving obstacles by checking full footprints and swept turn occupancy.

SR-042: all dynamic agent types (R, FL, HW). Detect predicted footprint conflicts; first try replanning. In narrow conflicts, calculate feasible retreat costs and move the lower-cost participant. This supersedes the old forklift-only waiting behavior.

SR-018: shared passage conflict resolution with alternative-path attempts, low-cost retreat and unresolved conflict reporting. Full certified clearance geometry is not implemented.

SR-012: first-in Handover Bay reservation for R / HW, with Waiting Zone routing when reachable and controlled release.

Usage instructions · Map compatibility · Scoring interpretation

Validation: choose a V3 map containing agents and task point pairs. The simulator reconstructs missing grid routes and reports inaccessible mission legs. Experiment: choose a geometry map and a V3 template, open Agent Task Generator and set each agent mission count/start step; generated goals preserve template roles and remain deterministically seeded.

Four nonnegative cumulative penalty terms: P_loss(t)=wRule·qR·rule exposure+wCollision·qC·chargeable contacts+wStep·actual movement steps+wWait·TW/TS. Current demonstration counts each global simulation tick as TS seconds; active safety waits are penalized, agent not yet started is not charged. The scores are illustrative, not risk-certification metrics. Collisions mean overlap of discretized geometry, not an injury prediction.

Imported V3 JSON layer aliases: robotZone → robotArea, forkliftZone → forkliftArea, bay → handoverBay, wait → waitingZone, dynamic → dynamicObstacle. Static hazards have an independent orange layer. Editor task point pairs may be used in Validation Mode; geometrically invalid routes are rejected rather than replaced with straight lines.
